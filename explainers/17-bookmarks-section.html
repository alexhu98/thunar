Part 1

What this PR adds

The side pane gets a new Bookmarks section between Places and Devices, and Places gains the standard folders. All of it lives in the shortcuts model and view, in three files under thunar/.

new in this PR as before

The big picture

Thunar used to list your bookmarks inside Places, right after Trash, with nothing to set them apart. To get a divider you had added a fake bookmark that points at your home folder, and since the GTK file chooser reads the same bookmarks file, that fake entry shows up there too as a real link. Nemo, another file manager, solves this with a separate Bookmarks section and the standard folders in Places. This PR does the same in Thunar.

The side pane is sorted by group, and each group is one bit in a list whose order is the display order. Adding two new groups for Bookmarks, its header and its entries, between Trash and Devices, is what makes the new section appear in the right place.

Step by step (numbers match the diagram)

① Thunar starts
  1. Places. As before, thunar_shortcuts_model_shortcut_places adds the Places header, Computer, Home and Desktop, then Recent and Trash.
  2. Standard folders. New: right after Desktop, the same function asks GLib for the Documents, Downloads, Music, Pictures and Videos folders from ~/.config/user-dirs.dirs. Each one that is set, is a folder and is not your home or Desktop folder is added to Places, in that order, with its standard icon. Symlinks are followed, so ~/Downloads opens wherever it points.
  3. Bookmarks. New: a Bookmarks header row, then every line of ~/.config/gtk-3.0/bookmarks in file order, now in their own group. The header hides itself when there are no bookmarks or all are hidden, and comes back as soon as the first bookmark is added.
  4. Devices, Network. Unchanged, except that their group bits moved up by one to make room for the Bookmarks groups.
② You use it
  1. Hide from header. Right-clicking the Bookmarks header now lists its bookmarks with show/hide boxes, like the other headers; thunar-shortcuts-view.c gained the Bookmarks branch for that menu. The standard folders are hidden from the Places header's menu. Hidden entries are stored in Thunar's settings, so they stay hidden after a restart: a bookmark by its address, a standard folder as places: plus its address, so hiding one doesn't hide the other.
  2. Edit bookmarks. Dropping a folder on the Bookmarks section, dragging to reorder, rename and remove work as before and still write the same bookmarks file. Only the group's name changed in the code.

When a folder shows

Only when it is set in user-dirs.dirs, exists as a folder, and is not your home or Desktop folder. The list is read when Thunar starts, so a change shows after a restart.

Same folder twice

A bookmark of a standard folder, such as Documents, also shows in Bookmarks, as in Nemo. Each copy hides on its own. Home and Desktop still share hiding with a bookmark of the same folder, as upstream does.

Hidden stays hidden

Bookmarks you hid before this change stay hidden. A hidden bookmark of a standard folder no longer hides that folder's new Places row.

Code review

Before the first push, a fresh agent ran /code-review at high with fixes on the branch against origin/main. It found 8 issues: 6 were fixed and 2 kept on purpose.

  • Fixed, header: the Bookmarks header now appears as soon as the first bookmark is added, not only after a restart.
  • Fixed, shared folders: a bookmark of Documents and the Documents place now both update when the folder is renamed or deleted, not just the first one found.
  • Fixed, standard folders: a standard folder that is the same as Desktop is skipped, and the folder check reuses Thunar's file cache instead of an extra disk lookup.
  • Fixed, comments: a new code comment was removed.
  • Skipped, S1: a standard folder you have bookmarked also shows in Bookmarks, as the issue asks. Hiding it later changed: see R2 below.
  • Kept, S2: the short comments on the new groups match the style of the list they are in.

CI then reviewed each code push at high. All its findings, R1 to R23, are in the code review comment on PR #112.

  • First review, of b7e59c0: R1 to R10. This session fixed R1, R3 to R7 and R9: one set of file handlers per model while another row uses the file, the user folder list reloaded, repeated standard folders skipped, and the test sets Pictures to home.
  • CI's fix commit 2e9f1b8: R11 to R16. Device rows connect their handlers the same way, the folder list reloads before Desktop is read, repeats are found by comparing folders, and the test checks are tighter.
  • R2, the owner's choice: a standard folder is now hidden apart from a bookmark of it, stored as places: plus its address (1eaa173).
  • CI's fix commit e81d7e4: R18 to R20. The test waits for the Downloads bookmark row, the watch-and-connect code is shared, and the repeat check is simpler.
  • Accepted by the owner: R8, five more folder lookups at startup, like Home and Desktop; R10, the folder list repeats part of Thunar's icon table for a different job; R17, Home and Desktop still share hiding with a bookmark.
  • Accepted as low: R21, a device row gets a folder icon after unmount, older than this PR; R22, standard folders found by sort order, maintainability only; R23, the test's menu position, right while no Places row is hidden.

Glossary

Side pane
The list of places on the left of a Thunar window.
Bookmarks file
~/.config/gtk-3.0/bookmarks: one folder address per line, shared with GTK file choosers.
user-dirs.dirs
~/.config/user-dirs.dirs: where your Documents, Downloads, Music, Pictures and Videos folders are.
Shortcut group
Each side pane row's kind, such as Places header or bookmark; rows are sorted by it.
Hidden list
The hidden-bookmarks setting in Thunar's xfconf settings: addresses of rows you hid; a standard folder's starts with places:.
Nemo
Linux Mint's file manager, whose side pane layout this follows.
Symlink
A file that points to another folder, like ~/Downloads pointing to /mnt/data/Downloads.
verify/17.sh
This PR's test script; CI runs it on a virtual screen (Xvfb) and keeps its screenshots.
Xvfb
A virtual screen with no monitor, used to run Thunar in tests.
