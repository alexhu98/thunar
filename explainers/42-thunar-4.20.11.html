What this PR adds

The big picture

The watcher from #30 turns each new Xfce release into an issue and a PR. Xfce has no release newer than main's 4.20.10 yet, so this test gives it a fake one and checks that the whole path, from tag to green PR, works.

Nothing here is from Xfce: thunar-4.20.11 exists only in a local fake repo. This PR is a draft and is closed after its checks.

Step by step (numbers match the diagram)

  1. Fake release. fake-upstream.sh made a local bare repo with upstream's real thunar-4.20.10 and a fake thunar-4.20.11: one commit that raises XDT_VERSION_INIT and adds a NEWS line.
  2. Check. check.sh, pointed at that repo, printed new thunar-4.20.11 (main has 4.20.10). Step 2 found no release issue or PR in flight, so the run opened #42.
  3. Merge the tag. On 42-thunar-4.20.11 from main, the tag merged with no conflicts, in a commit marked Review: suggest. The file-list check matched: every fork change survived.
  4. CI checks. CI builds the debs as 4.20.11, runs the smoke test and every verify/*.sh, and reviews the PR, as for a real release.
