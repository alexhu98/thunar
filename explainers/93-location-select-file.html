Part 1

What this PR adds

Enter on a path to a file goes to the file's folder, selects the file, scrolls it into view and puts the keyboard on it. Folder paths and missing paths behave as before. One source file changes: thunar/thunar-location-entry.c.

you new behaviour from this PR unchanged behaviour

The big picture

The location bar at the top of a Thunar window takes a typed path. Until now, Enter on a path to a file opened that file in its default app, and an executable script could even run. Usually you type a path to find a file, not to open it, so Thunar now does what Nautilus does: it shows the file in its folder, selected.

The location bar knows only its navigator, not the window. This PR finds the window when Enter is pressed and reuses the window's own “show and select files” helper, which already waits for a folder to load before selecting.

Step by step (numbers match the diagram)

① Enter on a file path
  1. Type, press Enter. You press Ctrl+L, type a full path to a file and press Enter. thunar_location_entry_activate runs, and now also takes the window the bar sits in.
  2. Poke the file. As before, thunar_browser_poke_file checks the file and mounts its location if needed. A remote path such as sftp:// finishes later, after the bar's temporary entry may have left the window, so the window is held and handed to the finish callback. If the window closed meanwhile, the callback does nothing.
  3. Open its folder. Instead of thunar_file_launch, the bar changes the current tab to the file's parent folder. The bar is then reset to show the folder, not the file, even when that folder was already shown.
  4. Select, scroll. thunar_window_show_and_select_files selects the file and scrolls to it. If the folder is still loading, the view keeps the selection and applies it once loading ends.
  5. Focus the view. The window's view takes keyboard focus. Without this, Enter on a file in the folder already shown left focus in the bar, because nothing else moved it.
② Other paths
  1. Folder path. Opens the folder as before, and adds it to Recent. A file that is only selected is no longer added to Recent.
  2. Missing path. The poke fails and shows the same “Failed to open” error as before.

Same tab

The issue warned that “Open Item Location” opens tabs per folder. This PR changes the current tab's folder instead, so you stay where you were typing.

Hidden files

A hidden file, with hidden files not shown, opens its folder with nothing selected. The issue accepts this.

Opening a file

To open a file you typed, press Enter again once it's selected, or double-click it.

Code review

Before the first push, a fresh agent ran /code-review high --fix against origin/main. It found 8 problems: it fixed 2 itself, the session fixed 2 more, one was this missing page, and 3 were left on purpose.

  • Fixed by the review: the bar kept showing the file's path when its folder was already shown; a comment had gone stale.
  • Fixed by the session: a remote path typed in the buttons bar's temporary entry finishes after that entry left the window, so the window is now taken on Enter (S1); a file that was only selected was added to Recent, and now only opened folders are (S3).
  • Left on purpose: a hidden file opens its folder with nothing selected, as the issue allows (S2); the shared helper reloads the just-opened folder, so it's read twice (S4); the function keeps its name open_or_launch to keep the diff from upstream small (S6).
  • CI reviews every code push too, and reports in the code review comment on PR #113.

  • Accepted by the owner, one by one: R3 hidden file, as the issue allows; R4 a remote path finishing after a tab switch, same as folders today; R5 the folder read twice, same as other callers.
  • Also accepted: R6 Enter on the folder shown keeps focus in the bar, as upstream; R7 finding the window by its toplevel, prior art; R8 comments only updated.

Glossary

Location bar
The path field at the top of a Thunar window; Ctrl+L focuses it.
Buttons bar
The location bar's other style, path buttons; typing opens a temporary entry.
Poke
Thunar's check that a file is reachable, mounting its location first if needed.
Navigator
The interface the bar uses to change the current tab's folder.
Recent
The recent:/// list of recently opened files and folders.
Hidden file
A file whose name starts with a dot; shown only after Ctrl+H.
verify script
verify/<issue>.sh: a test CI runs against the built Thunar on a virtual screen.
xdotool
A tool that types keys and finds windows, used to drive Thunar in tests.
Nautilus
GNOME's file manager, the model for this behaviour.
