Part 1

What this PR adds

One line in thunar/thunar-location-entry.c gives the toggle a 5 px start margin, and verify/68.sh measures both gaps on the screen in three toolbar layouts.

already in Thunar (#21) new in this PR

The big picture

Issue #21 added an Include subfolders toggle to the right of the search entry. Its right side had a 5 px gap to the search button, but its left side was glued to the entry's border, so it looked like part of the entry. Issue #68 measured 0 px on the left and 5 px on the right, and asked for 5 px on both sides.

The 5 px on the right was never the toggle's: it is DEFAULT_LOCATION_BAR_MARGIN (thunar/thunar-window.c:70), the margin around the whole location bar. The toggle itself had no margin, so the fix gives it the same 5 px on its start side.

Step by step (numbers match the diagram)

① Searching in Thunar — the fix
  1. Press Ctrl+F. The location bar turns into a search entry, and typing a word starts a search in the current folder.
  2. Toggle appears. The Include subfolders toggle shows at the entry's right end only while a search runs, and hides again after Escape. That behaviour comes from #21 and is unchanged.
  3. 5 px margin. In thunar_location_entry_init, where the toggle is created, the PR adds gtk_widget_set_margin_start (…subfolders_button, 5). The box that holds the entry and the toggle has no spacing, so this margin is the whole gap.
  4. Entry gives 5 px. The entry stretches to fill the space, so it is the one that gets 5 px narrower. The toggle keeps its size, and the gap from the toggle to the search button stays as it was.
② verify/68.sh — how it is checked
  1. Search, capture. The script opens Thunar at 1000×700 in a folder with match-top.txt and sub/match-sub.txt, presses Ctrl+F, types match, and captures the window with ImageMagick's import.
  2. Measure gaps. On each pixel row of the toolbar it marks pixels bright or dark and looks for the pattern shown below. It keeps only the rows where the toggle is at full width and fails unless both gaps are 5 px ±1.
  3. Three layouts. It restarts Thunar with the menu bar hidden, then in the header bar (client-side decorations on), and measures again. In the header bar the location bar has 15 px margins, so the gap to the search button is expected to be 15.
  4. Still works. The toggle's place must be plain entry before the search and after Escape. Clicking the toggle must change how it looks and re-run the search: the results are copied and pasted into a folder, and only match-top.txt may arrive.

The pattern step 6 looks for on one pixel row

dark run: every channel below 64 bright run: any channel 64 or more

The row comes from convert … txt:-, which prints one line per pixel, and awk groups it into runs. The awk sticks to what mawk, Ubuntu's default awk, understands.

How it was built and verified

The gap was matched to Thunar's own location bar margin, measured on screen in a sandbox like CI's, and the measuring was checked to fail on main's look. CI's run on PR #88 had not finished when this page was written.

Built on 3 known-good references

DEFAULT_LOCATION_BAR_MARGIN

5 px, thunar-window.c:70: the gap the toggle already had on its right. The new margin uses the same number.

Issue #68's measurement

0 px to the entry and 5 px to the button, on one pixel row with the menu bar shown. The script repeats that measurement.

The header bar's 15 px

thunar-window.c:2121 puts 15 px around the location bar in the header bar, so the script expects 15 on the right there.

Code review

A fresh general-purpose agent, given only the diff and the issue, reviewed the PR in this session. It found 3 things, all in verify/68.sh and none in Thunar's code, and all 3 were fixed before the first push.

  • Medium, idle check: the check that the toggle is hidden before a search could never notice a toggle that is always shown. It now needs a row of the toggle's place that is all the entry's inside colour.
  • Low, paste wait: the wait for the pasted results could end while the copy was still running. It now waits for the paste to settle.
  • Low, compare error: an error from compare counted as "the toggle changed". Only a pixel count above zero counts now.

CI's own review of the first push had not run when this page was written; it reports in the code review comment on PR #88.

Glossary

Include subfolders toggle
The button at the end of the search entry that switches searching in subfolders on and off (#21).
Search entry
The location bar's text field while you search, after Ctrl+F.
Location bar
The path field in the toolbar; it holds the search entry, the toggle and the search button.
Margin
Empty space GTK keeps around a widget; a start margin is on its left.
Header bar
The window's title bar drawn by Thunar itself (client-side decorations), with the toolbar inside it.
misc-use-csd
The Thunar setting that turns on client-side decorations, so the header bar is used.
Xvfb
A virtual screen with no monitor, where the tests run Thunar and take screenshots.
ImageMagick txt:
An output format that prints every pixel's position and colour as one text line.
mawk
Ubuntu's default awk, which lacks some GNU awk features.
Shot pair
A before and an after screenshot that CI joins into one image in its verify comment.
Shot-auditor
An agent that looks at each screenshot and says whether it shows what its caption claims.
