Part 1

What this PR adds

Two shortcuts now choose the scope of a search and save it on the folder, as a click on the Include subfolders toggle does. The change is in thunar-window.c, with a one-line fix in thunar-location-entry.c.

what you press new or changed in this PR unchanged, from #21

The big picture

Since #21, a search can include subfolders or not, set by the Include subfolders toggle beside the search box, and Thunar remembers that choice per folder. Ctrl+F always opened with the remembered choice, so the only way to change the scope was to reach for the mouse. Now Ctrl+F searches the folder you're in and Ctrl+Shift+F includes its subfolders.

A shortcut doesn't keep its scope to itself: it saves it on the folder, exactly as clicking the toggle does. So the toolbar Search button later opens there with the scope you used last, and no new setting is needed.

Step by step (numbers match the diagram)

① A shortcut — choose the scope, save it, search
  1. Ctrl+F. Searches only the folder you're in. The Go menu's “Search for Files...” item shows Ctrl+F and does the same. Both now call thunar_window_action_search_folder.
  2. Ctrl+Shift+F. A new action, search-subfolders, labelled “Search in Subfolders...”: it searches the folder and everything under it. It's listed in the keyboard shortcut editor, so you can rebind it. It isn't added to the Go menu.
  3. Save the scope. Both shortcuts go through one helper, thunar_window_search_in_scope. Before the search starts, it calls thunar_file_set_search_subfolders on the current folder with off or on, the same call a click on the toggle makes.
  4. Search opens. The search box appears with the toggle released or pressed to match, and the results follow it. The toggle now re-reads the folder's choice on every change to the search text, not only when it first appears (a local review fix, below).
  5. Press again. While a search is running, Ctrl+F or Ctrl+Shift+F ends it and shows the folder again, as Ctrl+F did before. It doesn't switch the scope; the toggle does that.
② Toolbar button or Search key — the saved choice
  1. Toolbar or key. The toolbar's Search button and the keyboard's Search key behave as before. The button is built from the Ctrl+F action, so the PR swaps its click handler for the saved-choice one right after it's created.
  2. Saved choice. They save nothing and open with the folder's last scope, or, in a folder never searched, the global “Include subfolders” preference. This part is #21's, unchanged.

A closer look at the change

  if (window->is_searching == FALSE)

      if (scope != THUNAR_WINDOW_SEARCH_SAVED && window->current_directory != NULL)
        thunar_file_set_search_subfolders (window->current_directory,

Three scopes, one helper

Saved, folder or subfolders. Ctrl+F passes folder, Ctrl+Shift+F passes subfolders, and the toolbar button and Search key pass saved, which skips the save.

The toggle stays in sync

A search typed by hand after Ctrl+L doesn't count as running, so a shortcut then starts a new one while the toggle is showing. The toggle used to keep its old state; it now updates on every text change.

Once Thunar drops it, the toolbar button falls back to the global preference. #21's toggle behaves the same today; a per-window fallback would be a new mechanism. Glossary

Include subfolders toggle
The button beside the search box, from #21, that switches a search between this folder and its subfolders.
Scope
Where a search looks: only the current folder, or the folder and every folder under it.
Saved choice
The scope Thunar remembers per folder, written as a hidden metadata entry on the folder.
Global preference
“Include subfolders” in Thunar's preferences, used in folders that have no saved choice.
gvfs / GIO metadata
The desktop service that stores per-file notes such as the saved choice; without it nothing is written.
Action
A named command in Thunar's window, with a label and a default shortcut you can change in the shortcut editor.
Search key
A dedicated key on some keyboards; Thunar binds it to the search action called search-alt.
Verify script
verify/<issue>.sh: drives Thunar with simulated keys under a virtual screen, checks the result and takes screenshots.
Xvfb
A virtual X display with no monitor, where the verify scripts run Thunar.
shot-auditor
A separate agent that reads each screenshot and says whether it shows what it claims.
S1, S2
Findings the local review skipped rather than fixed, numbered for you to decide on.
