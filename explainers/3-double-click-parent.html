Part 1

What this PR adds

The icon, compact and details views now react to a left double-click on blank space by running the existing Open Parent action, if the new misc-double-click-blank-go-up preference is on.

added by this PR existing Thunar code, reused you

The big picture

Nemo, the file manager this fork borrows ideas from, goes up one folder when you double-click an empty part of the window. Thunar had no mouse shortcut for that: you had to use the Up button or Alt+Up. This PR adds the shortcut without writing a new "go up" path. The click is handed to the same Open Parent action the Up button and Alt+Up already use.

Each view already "focuses" the pane under the pointer before anything else runs. That is why, in split view, the double-click acts on the pane you clicked: by the time Open Parent runs, that pane is the window's active one.

Step by step (numbers match the diagram)

① Double-click — the folder goes up
  1. Double-click. GTK delivers a double-click as two ordinary presses followed by a "2-button press" event. The ordinary presses are only noted, never consumed, so a single click and the drag of a rubber-band selection work as before.
  2. View checks. On every left press, the icon and compact views (thunar-abstract-icon-view.c) ask exo_icon_view_get_item_at_pos whether an item is under the pointer. The details view (thunar-details-view.c) uses the row lookup it already did, and clicks on the column headers never reach this code. The answer goes to the helper.
  3. Shared helper. _thunar_standard_view_blank_button_press in thunar-standard-view.c remembers the folder and how many presses in a row hit blank space. On the 2-button press it runs Open Parent only if both presses hit blank space in the same folder, with no modifier keys, the preference on and single-click mode off. So if the first click already opened a folder, the second can't send you back up. It is shared, so the three views can't drift apart.
  4. Open Parent. The helper looks up THUNAR_WINDOW_ACTION_OPEN_PARENT and calls its callback, as the icon view's swipe-up gesture already does. At / that action finds no parent and returns quietly, without a dialog.
② Preferences — on or off, right away
  1. Checkbox. thunar-preferences-dialog.c adds "Double-click on a blank area to open the parent folder" on the Behavior tab, right under "Double click to activate items". The issue calls that section "Mouse Interactions"; in this Thunar it is titled "Navigation".
  2. xfconf property. thunar-preferences.c adds the boolean misc-double-click-blank-go-up, default on. The checkbox is bound to it both ways, and the helper reads it on every double-click, so a change applies at once without a restart.

Then CI's review of ad5d5e1 (Opus at xhigh): 12 findings, 2 confirmed medium. Both mediums and the related ones are fixed in 4fb336d. CI's review of that commit pushed one claude[bot] fix commit (de857eb) for two lows: in single-click mode the checkbox is now greyed out (R13), and the icon view no longer allocates a tree path only to free it (R14). Its re-review found 6 more lows (R22 to R27), none confirmed.

  • Fixed, R1, R2, R5 (medium): the blank-space check ran only at the 2-button press, so if the first click had already opened a folder (single-click mode, or the details view on the second press), the empty new view counted as blank and Open Parent sent you straight back. Now both presses must hit blank space in the same folder, and it is off in single-click mode.
  • Fixed, R6 and R7 (low): single-click mode is skipped, so a release can't activate a parent-folder row, and the never-taken action_entry == NULL branch was removed.
  • Fixed, R3 and R4 (low, tests): verify/3.sh now double-clicks a folder in details view and in single-click mode, and checks that the right pane stays on alpha after the left pane goes up.
  • Kept, low: the icon view's rubber band from the second press stays active until the release; the empty strip right of the details columns counts as a row (the issue asks for the space below the rows); the callback cast and comments follow existing Thunar code; the default is on, as the issue says. CI rated R9 to R12 not confirmed.

Glossary

Blank space
Part of the file view with no file or folder under the pointer.
Icon / compact / details view
Thunar's three layouts, switched with Ctrl+1, Ctrl+3 and Ctrl+2.
Split view
Two folder panes side by side in one window (F3).
xfconf
Xfce's settings store; Thunar's preferences live in its thunar channel.
2-button press
The extra event GTK sends on the second press of a double-click.
Xvfb
A virtual X display with no screen, used to run Thunar in tests.
xdotool
A tool that moves the pointer, clicks and types into X windows from a script.
Mnemonic (Alt+P)
The keyboard shortcut for a labelled control; the underlined letter of "parent".
