PR #154: Ctrl+F now searches subfolders too

PR #154, branch 149-swap-search-shortcuts → main, closes #149. The two search shortcuts from #139 trade places: Ctrl+F searches the folder and its subfolders, and Ctrl+Shift+F searches only the folder you're in.

Part 1

What this PR adds

Two default shortcuts swap in thunar/thunar-window.c, and the Go menu gains Search in Subfolders... above Search for Files.... Nothing else about searching changes.

changed by this PR what you see (search logic unchanged) you: the keys you press and your settings

The big picture

Thunar's search can look only in the folder you're in, or in it and every folder below it. #139 gave each scope its own shortcut: Ctrl+F for the folder alone, Ctrl+Shift+F for its subfolders too. You search subfolders far more often, so this PR gives that one the easier key.

Only the default keys move. Each action keeps its name, menu label and behaviour, so the menu items now simply show the other shortcut. Two small extras came from CI's review: a new Go menu letter and a toolbar tooltip (steps 7 and 9).

Step by step (numbers match the diagram)

① Ctrl+F — the folder and its subfolders
  1. Ctrl+F. Pressing it in a folder view now starts a search of the folder and its subfolders. Before this PR it searched the folder alone.
  2. Subfolder action. Ctrl+F is now the default key of the search-subfolders action, labelled Search in Subfolders... in menus. Only its key in the action table changed.
  3. Saves scope: on. As since #139, the action saves “include subfolders” on the folder, so the toggle shows pressed and the results include matches in subfolders.
② Ctrl+Shift+F — only this folder
  1. Ctrl+Shift+F. Pressing it now searches only the folder you're in. Before this PR it included subfolders.
  2. Folder action. Ctrl+Shift+F is now the default key of the search action, labelled Search for Files... in menus.
  3. Saves scope: off. The action saves “this folder only” on the folder, so the toggle shows released and only the folder's own files are listed.
③ Around the shortcuts
  1. Go menu. The Go menu listed only Search for Files.... It now lists Search in Subfolders... first, so the Ctrl+F item comes first. The issue offered this as optional; it's done. Both items used S as their menu letter, so CI's review moved Search in Subfolders... to U: Alt+G then U searches with subfolders, Alt+G then S only the folder.
  2. Your shortcuts. If you rebound either action in ~/.config/Thunar/accels.scm, your binding stays, because it is stored under the action's name, which hasn't changed.
  3. Toolbar button. The toolbar Search button and the Search key still open with the folder's saved choice, which the last shortcut you used there set. The button had borrowed Search for Files...'s tooltip, which said “current folder”; CI's review gave it its own: “Search for a specific file in the current folder, with its saved Include subfolders choice, and Recent”.

Glossary

Scope
Where a search looks: only the current folder, or the folder and every folder under it.
Include subfolders toggle
The button beside the search box, from #21, that switches a search between those two scopes.
Saved choice
The scope Thunar remembers per folder; each shortcut and each toggle click writes it.
Action
A named command in Thunar's window, with a menu label and a default shortcut you can change.
Accelerator
GTK's word for a keyboard shortcut; <Primary> means Ctrl.
accels.scm
The file in ~/.config/Thunar/ where your changed shortcuts are stored, by action name.
Search key
A dedicated key on some keyboards; Thunar binds it to the search action called search-alt.
Verify script
verify/<issue>.sh: drives Thunar with simulated keys under a virtual screen, checks the result and takes screenshots.
Verify: full
A commit trailer that makes CI run every verify script instead of only this PR's.
S1, S2
Findings the local review skipped rather than fixed, numbered for follow-up.
R1, R2
Findings of CI's code review, numbered across the whole PR.
Menu letter
The underlined letter of a menu item; pressing it while the menu is open picks that item.
